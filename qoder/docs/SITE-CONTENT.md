# 文献笔记智能检索助手

## 一、要解决的问题

复习和写论文时，资料散落在几十个 PDF、课程笔记和 Markdown 文件里。想找"上次记的那个概念"，只能靠文件名和记忆，翻半天找不到；找到了也说不清是哪份材料、哪一段。

## 二、项目做了什么

把资料导入 **OceanBase seekdb**，用自然语言直接检索，返回相关段落、相似度分数和出处（文件名 + 块序号）。

**核心功能：**

| 功能 | 说明 |
|---|---|
| 文档导入 | 支持 PDF / TXT / Markdown，按段落优先策略切块 |
| 向量检索 | 文本转向量存入 seekdb，用 `l2_distance` 召回语义相近内容 |
| 全文检索 | seekdb `FULLTEXT` 索引 + ik 分词，关键词精确匹配 |
| 混合检索 | 全文召回 + 向量精排两阶段，加权融合排序 |
| 文档筛选 | 下拉框选择单篇文档，只在其中检索 |
| 出处定位 | 每条结果给出文档名与块序号，可回溯原文 |

## 三、技术架构

```
浏览器（上传 / 检索）
        │
        ▼
FastAPI（app/main.py）
        │
        ├── ingest.py      解析 PDF / TXT，分段切块
        ├── embedding.py   文本 → 向量（哈希 + 子线性 TF，L2 归一化）
        └── store.py       seekdb 建表、写入、检索
                │
                ▼
      seekdb（Docker，端口 2881）
```

**seekdb 在项目中的作用（关键）：**

- **存储**：`doc_chunks` 表，含 `VECTOR(256)` 向量列与 `FULLTEXT` 全文索引
- **向量检索**：`l2_distance(vector, %s)` 计算相似度
- **全文检索**：`MATCH(content) AGAINST(%s)` 走 ik 索引
- **混合检索**：一条 SQL 同时取向量分与全文分，Python 侧归一化加权
- **结构化过滤**：`WHERE doc_name = %s`

seekdb 是项目**唯一的数据底座**，移除它项目无法检索。

## 四、混合检索是怎么做的

**第一阶段 —— 全文召回**

用 `MATCH...AGAINST` 筛出关键词命中的文本块，候选池为最终结果的 4 倍（至少 10 条）。

**第二阶段 —— 向量精排**

对候选池每条同时计算 `vec_score = 1 - l2_distance` 与 `kw_score`，分别归一化后加权：

```
最终得分 = 0.6 × 归一化全文分 + 0.4 × 归一化向量分
```

全文权重略高，保证关键词精确命中优先；向量负责语义补位。

## 五、功能演示

| 场景 | 输入 | 实际结果 |
|---|---|---|
| 语义检索 | 「近似最近邻检索怎么加速」 | 命中「向量索引与近似最近邻」段落 |
| 全文检索 | 「隔离级别」 | 命中 3 条含该词的片段，得分 0.72 / 0.51 / 0.28 |
| 文档筛选 | 「隔离级别」+ 指定文档 | 仅返回该文档内结果，首条得分 0.93 |
| 故障提示 | 停掉 seekdb 后检索 | 返回 503 +「请检查 seekdb 是否启动」 |

## 六、运行方式

```bash
# 1. 启动 seekdb
docker run -d --name seekdb -p 2881:2881 -p 2886:2886 \
  -v ./data:/var/lib/oceanbase oceanbase/seekdb:latest

# 2. 安装依赖
pip install -r requirements.txt

# 3. 启动服务
uvicorn app.main:app --host 0.0.0.0 --port 8000
```

浏览器打开 `http://127.0.0.1:8000`。

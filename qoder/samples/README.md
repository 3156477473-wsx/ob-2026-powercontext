# 验证样例

本样例给出一组可直接执行的输入，验证「导入 → 检索 → 出处定位」主流程，以及 seekdb 在其中的实际作用。

## 初始数据

`sample-notes.md` 是一份虚构的课程笔记（无需真实论文），包含若干个可检索的知识点：

- 结构化查询语言的执行计划
- 向量索引与近似最近邻
- 事务隔离级别
- 机器学习中的过拟合与正则化

## 操作步骤

### 步骤 1：启动环境

按 README 启动 seekdb 与服务，浏览器打开 <http://127.0.0.1:8000>。

预期：页面顶部徽标显示「seekdb 已连接」，文档数 0、文本块数 0。

### 步骤 2：导入样例

点击「选择文件」，选中 `samples/sample-notes.md`，点「上传并建索引」。

预期：提示「已导入 sample-notes.md：N 个文本块」，统计数字更新为 1 文档 / N 文本块。

### 步骤 3：语义检索（验证向量能力）

搜索框输入：

```
近似最近邻检索是怎么加速的
```

模式选「混合检索」，点击搜索。

预期：返回至少 1 条结果，第一条来自 `sample-notes.md`，内容与「向量索引 / 近似最近邻」相关，显示相似度分数与块序号。

### 步骤 4：关键词检索（验证全文能力）

搜索框输入：

```
隔离级别
```

模式选「仅全文」，点击搜索。

预期：命中包含「隔离级别」的文本块，说明 seekdb 全文索引生效。

### 步骤 5：验证 seekdb 实际参与

在终端执行：

```bash
docker exec seekdb mysql -h127.0.0.1 -P2881 -uroot -e \
  "SELECT doc_name, chunk_no, LEFT(content, 40) AS preview FROM test.doc_chunks LIMIT 5;"
```

预期：能看到步骤 2 导入的数据行，说明数据确实存放在 seekdb 中，检索结果来自 seekdb 查询而非内存。

## 对照实验（可选）

点「清空索引」后再次搜索相同关键词。

预期：返回「没有找到相关内容」，说明检索结果依赖 seekdb 中的索引数据。
